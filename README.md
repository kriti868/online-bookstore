# BookHaven - Online Bookstore

A front-end online bookstore built with HTML5, CSS3 and JavaScript.

## Features
- User registration and login with form validation
- Profile page with edit option
- Book catalog with search and category filter
- Shopping cart with quantity update and tax calculation
- Simulated payment and order confirmation
- Data saved using browser localStorage

## Technologies
- HTML5
- CSS3
- JavaScript (DOM, localStorage)

## How to Run
Open index.html in any browser.
